# Dungeon Crawler Game (C++ with SFML)

## Overview
A 2D Dungeon Crawler Game demonstrating Data Structures and Algorithms in an interactive environment.

## Features
- Procedural Dungeon Generation (BSP)
- A* Pathfinding Enemy AI
- Fog of War
- Inventory System

## Algorithms Used
- Binary Space Partitioning (BSP)
- A* Pathfinding
- Minimum Spanning Tree (MST)
- Bresenham Line Algorithm

## Data Structures
- Graph (Adjacency List)
- Trees (BSP)
- Priority Queue (Heap)
- HashMap
- 2D Grid

## Technologies
- C++
- SFML
